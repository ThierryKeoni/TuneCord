## TuneCord 1.0.1

### Fixed
- 🎵 **TIDAL on Windows is detected again.** When the TIDAL app doesn't report the song to Windows, TuneCord now reads it from the TIDAL window instead. Song length and album are looked up automatically, so the progress bar still works. Play/pause and next/previous work through your media keys.

### Improved
- 🔍 The Activity log (Settings) now shows exactly which players Windows reports, so it's easier to see why a player isn't picked up.

Note: when TIDAL is minimised to the system tray, Windows hides its window title. Keep TIDAL open or minimised to the taskbar.
