## TuneCord 1.0.3

### Fixed
- 🪟 **Windows: no music detected at all.** The background helper that reads "now playing" from Windows froze right after starting, so no player ever showed up: TIDAL, Spotify, Apple Music or anything else. It now really works in the background.
- ⏱️ A music app that doesn't answer Windows can no longer freeze detection for all other players.

### Improved
- 🐶 A watchdog restarts the helper by itself if it ever stops answering, and says so in Settings → Activity.
